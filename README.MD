# CV Personnel Interactif - Hicham TERFANI

##  Description

Ce projet est un CV personnel interactif réalisé dans le cadre du module Programmation Web 2.

Le site présente :
- Mon profil personnel
- Mon parcours académique
- Mes compétences techniques
- Mes projets
- Mes informations de contact

Le projet utilise :
- HTML5
- CSS3
- JavaScript
- jQuery
- ReactJS

---

##  Fonctionnalités

- Interface responsive
- Dark Mode 🌙
- Animations jQuery
- Barres de progression animées
- Cartes de projets interactives
- Design moderne et professionnel
